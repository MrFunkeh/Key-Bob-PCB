# Key Bob
<img width="871" height="814" alt="image" src="https://github.com/user-attachments/assets/cc4afd94-53ec-4a15-a466-503a875288be" />

Key Bob is a small cube that you move around to interact with or use the dial and button to switch between characters. This project was inspired by the tomagotchi and the STARBIE, I wanted to make something somewhat in between the two but with more capabilities and in a small package.
